# Changelog

## 0.0.1 (2025-01-28 14:04:34 UTC)

Initial release by [@Penguin5681](https://github.com/Penguin5681) 🎉

### Added
- ✨ Core flash message functionality
  - Four message types (success, error, info, warning)
  - Three position options (top, center, bottom)
  - Customizable durations
  - Auto-dismiss feature

- 🎨 Styling features
  - Default color schemes for each message type
  - Custom background color support
  - Custom text color support
  - Custom icon support

- ⚡ Animation and interaction
  - Smooth slide-in/slide-out animations
  - Tap-to-dismiss functionality
  - Custom tap action support

- 📱 Display features
  - Support for message title
  - Optional description text
  - Adaptive positioning with SafeArea support

- 🛠️ Developer features
  - Simple API with FlashMessageService
  - Easy setup with FlashMessageOverlay
  - Zero external dependencies

### Notes
- First public release
- Tested on Flutter stable channel
